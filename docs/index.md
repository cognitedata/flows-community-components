# Component Library Documentation

A comprehensive collection of React components built with ShadCN/UI and Tailwind CSS.

## Components

### Form Components
- [Button](./components/button.md) - Interactive button component with multiple variants
- [Input](./components/input.md) - Text input field with validation states
- [Textarea](./components/textarea.md) - Multi-line text input component
- [Label](./components/label.md) - Form field labels with accessibility features
- [Switch](./components/switch.md) - Toggle switch for binary choices
- [Checkbox](./components/checkbox.md) - Checkbox input with indeterminate state
- [Select](./components/select.md) - Dropdown selection component

### Layout Components
- [Card](./components/card.md) - Flexible container for grouping content
- [Separator](./components/separator.md) - Visual divider for content sections
- [Tabs](./components/tabs.md) - Tabbed interface component
- [Accordion](./components/accordion.md) - Collapsible content panels

### Feedback Components
- [Badge](./components/badge.md) - Small status indicator
- [Progress](./components/progress.md) - Progress bar component
- [Skeleton](./components/skeleton.md) - Loading placeholder component
- [Sonner](./components/sonner.md) - Toast notification system

### Overlay Components
- [Dialog](./components/dialog.md) - Modal dialog component
- [Alert Dialog](./components/alert-dialog.md) - Confirmation dialog
- [Popover](./components/popover.md) - Floating content container
- [Tooltip](./components/tooltip.md) - Contextual information on hover
- [Sheet](./components/sheet.md) - Slide-out panel component

### Navigation Components
- [Dropdown Menu](./components/dropdown-menu.md) - Context menu component
- [Navigation Menu](./components/navigation-menu.md) - Main navigation component

### Data Components
- [Table](./components/table.md) - Data table component
- [Calendar](./components/calendar.md) - Date picker component

## Usage Guidelines

All components are designed to work together as a cohesive system. They follow consistent design patterns and accessibility standards.

### Import Pattern
```tsx
import { ComponentName } from "@/components/ui/component-name"
```

### Styling
Components use Tailwind CSS for styling and support both light and dark themes through CSS variables.
