Map layouts pair a geographic or spatial view with panels and grids. Choose the layout based on what the user needs next to the map.

## Left panel + map + right panel

The user controls what appears on the map — layers, models, visibility toggles — and inspects one selected item. The left panel holds a search and a checkbox tree; the right panel shows a preview with actions.

## Map + right panel

The map is the main product. The user finds and inspects one item at a time with no layer controls. This layout gives the map the most space.

## Horizontal split: map + data grid + right panel

The user works with records that are both spatial and tabular. A page header names the view, a data grid sits under the map for scanning and selecting, and the right panel shows detail on demand.

## Horizontal split: map + data grid

The user scans and acts on many records where the grid is the primary detail. No side panel — row actions and a details page are enough. The data grid spans the full width.
