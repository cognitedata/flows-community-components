A read-only operations overview. Pick a layout when the page is for glancing at plant status, not for working a long list of records.

## Dashboard + header

One standalone page. The header holds the title, a short description, and one primary action.

## Dashboard + tabs

Several sibling views of the same dashboard, such as Overview, Production, Energy, and Alarms. Tabs replace the title. There is no page-level action.

## Left panel + dashboard + header

The dashboard changes with a scope the user picks, such as a site, unit, or well. The left panel is persistent navigation or a quick filter, and the header still names the page.

## Left panel + dashboard + tabs

The panel picks the scope and the tabs pick the view inside that scope. They are different levels of navigation.

## Dashboard + data grid + header

A compact row of metrics, then a grid people scan, sort, and act on. Checkboxes are here because bulk actions are expected. The primary action sits in the grid toolbar.

## Dashboard + data grid + tabs

The same summary and grid, under sibling tabs. The primary action, when there is one, stays in the toolbar under the tabs.

## Dashboard + data grid + right panel + header

Single-select. The preview stays closed until a row is selected, then opens on the right. There are no checkboxes.

## Dashboard + data grid + right panel + tabs

The same single-select grid and preview, with tabs instead of a page header.
