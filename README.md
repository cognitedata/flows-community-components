# 🎨 Design Vibecoding Repo

This is our shared space for experimenting with Cursor + GitHub. Each designer can create their own folder here to store prototypes.

---

## Why use GitHub with Cursor?

Running Cursor locally is fine, but connecting to GitHub means:

- ✅ **Share with developers easily** — they can pull your prototype straight from the repo.  
- ✅ **Version control for free** — roll back or compare changes anytime.  
- ✅ **Inspiration across the team** — explore each other’s projects side by side.  

---

## Getting Started (3 minutes)

1. **Clone this repo in Cursor**  
   - Press `Cmd+Shift+P` in Cursor → search **Git: Clone**  
   - Paste this URL:  
     ```
     https://github.com/cognitedata/design-vibecoding
     ```  
   - Save it somewhere like `Documents/Projects/`.  

2. **Make your own folder**  
   - Inside the repo, create a folder named after you or your project (e.g. `/sam_project/` or `/dms-prototype/`).  
   - Add your prototype files (`index.html`, `script.js`, `styles.css`, etc.).  

3. **Commit & Push from Cursor**  
   - Go to the **Source Control** tab (left sidebar).  
   - Write a short commit message like *“Add first prototype”*.  
   - Hit **Commit & Push**.  

4. **Share & explore**  
   - Developers can pull the repo and run your prototype directly.  
   - Designers can browse each other’s work for inspiration.
